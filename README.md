## INSIGHT FitCheck App

Our in-house desktop tool for one specific problem: a single cut has to run on a dozen platforms, and each one crops, pads and covers the frame differently.

FitCheck puts the footage inside each platform's real interface before delivery and reports what will be lost — crop ratio, safe area, and UI collisions (caption bars, CTA strips, button columns) — with frame-accurate timecodes. Review notes, version comparison and client sign-off run on the same timeline.

It also exposes a **local MCP server**, so an AI client can drive the check engine directly:

```
check_fit  inspect_clip  list_platforms  share_clip
list_notes  summarize_notes  list_batches  summarize_batch
room_protocol  read_guide
```

Transport is stdio and local. Footage is decoded on the machine and never uploaded — no cloud service, no account, no queue.

Platforms covered: Douyin, WeChat Channels, Kuaishou, Xiaohongshu, Moments, Taobao, JD, Weibo, Bilibili, TikTok, YouTube, Instagram.
